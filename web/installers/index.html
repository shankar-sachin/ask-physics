Install Ask Physics

Pick whichever fits your machine. Every option puts the askphysics command in its own environment, away from your system Python, and needs no account or API key.

One line

The quickest way. It installs uv first if you don't have it.

macOS and Linux

bash

Paste into a terminal.

curl -fsSL https://askphysics.vercel.app/install.sh | bash

Windows

PowerShell

Paste into PowerShell (Windows PowerShell 5.1 or 7+).

irm https://askphysics.vercel.app/install.ps1 | iex

Package managers

Homebrew

macOS and Linux
brew install shankar-sachin/tap/askphysics

WinGet

Windowspending

Available once the package is accepted into WinGet. Until then, use the installer or the one-liner above.

winget install ShankarS.AskPhysics

Windows installer

AskPhysicsSetup.exe

Windows

A normal setup program, if you would rather click than type. It is the latest release's installer.

Download for Windows

Read the scripts first

The one-liners just download and run these two files. Fetch one, read it, then run it yourself.

install.sh install.ps1

Both are copied unchanged from the repository.

Then ask

The Fermi models download automatically, either at install or on your first question, so there is nothing else to run.

askphysics ask "How fast does a ball dropped from 20 m hit the ground?"

Developer?

Pin a version, install from a branch or a local checkout, skip the model download, uninstall, or see every release: more options for developers.
